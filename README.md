# 🍰 Sweet Crumbs – Online Cake Shop

A responsive online cake shop website developed using **HTML, CSS, and JavaScript**.

## 📌 About the Project

Sweet Crumbs is a front-end web development project created to practice HTML, CSS, and JavaScript concepts.

The project was developed by following and learning from the **GeeksforGeeks tutorial** on designing an online cake shop website. I used the tutorial as a learning reference and customized the project while practicing the concepts.

## 🚀 Features

* Responsive navigation bar
* Home section
* Cake categories
* Product listing
* Cake images and pricing
* About section
* Contact section
* Responsive design
* JavaScript-based interactions
* Mobile-friendly layout

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Font Awesome

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.

You can also use the **Live Server** extension in VS Code.
